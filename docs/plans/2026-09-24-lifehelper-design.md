# LifeHelper — дизайн v1

Дата: 2026-09-24. Личная система для одного человека: сайт + Telegram-бот + Chrome-расширение.

## Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Язык | Русский | так попросил владелец |
| Хостинг | Cloudflare Workers + D1, деплой из GitHub Actions | GitHub Pages — только статика; боту нужен вебхук 24/7. Free tier Cloudflare покрывает с запасом |
| Вход | Только через Telegram (deep-link `/start login_<code>`) | «чтобы никто не портил статистику»; не нужен домен для Login Widget |
| Владелец | `OWNER_TELEGRAM_ID` или первый вошедший | не нужно заранее знать свой ID |
| Секрет вебхука | sha256 от токена бота | на один секрет меньше |
| Дизайн | как KoboCRM: тёмная тема, мятный акцент, Playfair Display + Manrope + JetBrains Mono | так попросил владелец |
| Фронт | React + Vite, без UI-кита и роутер-библиотек | маленький, быстрый, ничего лишнего |
| Расширение | MV3 без сборки | ставится «распакованным» за минуту |

## Модель

- **goals** — глобальная цель: дедлайн, «зачем», либо числовая (12 книг), либо через привычки.
- **habits** — ежедневная норма: галочка или минуты, дни недели, `start_url`, `focus_sites`, `blocking`.
- **habit_logs** — (привычка, дата) → done, minutes. В цель засчитывается `max(minutes, норма)` если отмечено.
- **days** — пропуск, настроение, заметка, служебные флаги бота (защита от двойной отправки).
- **tasks**, **accounts/transactions**, **wishes**, **stickers**, **focus_sessions**, **site_time**.

Все даты — строки `YYYY-MM-DD` в часовом поясе владельца.

## Правила

- **День успешен**, если сделаны все запланированные привычки. Пропуск и пустой день — нейтральны (не рвут и не растят стрик). Сегодняшний незавершённый день — нейтрален.
- **Стрик «до вчера»** кэшируется в settings; сбрасывается при любой правке прошлого. Расширение опрашивает сервер каждую минуту и не читает всю историю.
- **Пропуск** — на сегодня или вчера, не больше N в неделю (Пн–Вс). Подтверждение: сайт/расширение — 20 секунд на кнопке; бот — сервер отклоняет «Да» раньше 20 секунд после запроса.
- **Темп цели**: план = Σ нормы по запланированным дням от старта до дедлайна; «где должен быть» = план до вчера; «нужно в день» = остаток / план с сегодня; прогноз финиша — при работе строго по норме.
- **Расширение**: блок действует, если есть несделанная привычка с `blocking`, нет пропуска и сейчас внутри окна блокировки. Сайт из `focus_sites` не блокируется и сам запускает фокус-сессию. Время засчитывается только при активности (ввод за последнюю минуту или играющее видео).

## Поток «вечер»

Крон (каждую минуту) → наступило `evening_time` и флаг `evening_sent` удалось атомарно взять → сообщение с кнопками `t:<date>:<habit>` / `m:<date>:<mood>` / `sk:<date>` / `cl:<date>` → каждое нажатие редактирует то же сообщение.

## Проверка

`tests/e2e.test.mjs` поднимает `wrangler dev` на чистой базе с фейковым Telegram API и проходит: закрытый API, вход владельца и отказ чужому, CSRF, стрик по истории и его пересчёт, пропуск и недельный лимит, чек-лист в боте и 20-секундную защиту, быстрые траты/задачи/вишлист/стикеры, токен и heartbeat расширения, однократность крона, экспорт.
